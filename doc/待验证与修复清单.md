## 0. 环境与构建

- 平台：macOS 26（`Package.swift` 指定 `.macOS("26.0")`），Swift 6.0（**strict concurrency**），依赖 GRDB 7.11+。
- 工程有两套：SwiftPM（`MantaPhotos/Package.swift`）+ XcodeGen（`MantaPhotos/project.yml` 生成 `MantaPhotos.xcodeproj`）。
- **重要**：本轮新增了多个 `.swift` 文件。SwiftPM 按目录 glob 会自动包含；但 `MantaPhotos.xcodeproj` 若不重生成可能漏掉新文件 → **先 `cd MantaPhotos && xcodegen generate` 再用 Xcode 打开**。

构建 / 测试命令：

```bash
cd MantaPhotos
# 1) 命令行编译核心 + 可执行
swift build
# 2) 跑单元测试（Swift Testing，含 migration 测试）
swift test
# 3) Xcode（GUI 运行 / 沙箱 entitlements 生效）
xcodegen generate
open MantaPhotos.xcodeproj   # 选 MantaPhotosMac scheme 运行
```

> 注：沙箱权限（照片库、用户选择文件、安全作用域书签）只有在 Xcode 签名运行的 app bundle 下才完整生效；`swift run` 的裸可执行不一定带 entitlements。本地目录源的真机验证请用 Xcode 运行。

## 2. 优先级最高：编译风险热点（先看这些）

按「最可能编译报错」排序，逐个确认：

### 2.1 Swift 6 严格并发

- `Infrastructure/Sources/LocalMediaSupport.swift` → `LocalThumbnailProvider.requestThumbnail`
  - `queue.async { [weak self] in ... Task { @MainActor in completion(image) } }`：依赖 region-based isolation 把本地 `NSImage` 送进主线程。若报「non-Sendable captured by sending closure」，改为：在后台先得到 `image`，用 `MainActor.assumeIsolated` 或把 `image` 包进一个 `@unchecked Sendable` 盒子再回主线程。
  - 确认捕获的 `completion`（`@MainActor @escaping`）被视为 Sendable。
- `Infrastructure/Photos/PhotoThumbnailProvider.swift` → `requestSystemThumbnail` 里 `Task { @MainActor in completion(image) }` 同上。
- `App/PhotoLibraryViewModel.swift` → `runLocalImport` 的 `Task.detached(priority: .utility) { try await importer.importAll() }`：确认 `LocalDirectoryImporter` 的 `Sendable` 成立（其成员 `PhotoAssetRepository`/`String`/`URL` 均 Sendable）。
- `Domain/AnalysisScheduler.swift` → `score(...)` 新增的本地分支在 actor 外的 TaskGroup 子任务里调用 `PhotoSourceRegistry.shared` 与 `LocalMediaProvider()`：确认无 actor 隔离报错。
- `Presentation/Photos/PhotoViewerView.swift` → `@State private var thumbnailToken: ThumbnailRequestToken?`：`ThumbnailRequestToken` 是 class，放 `@State` 仅作存储，应可；若 SwiftUI 抱怨，改为普通属性或包一层。

### 2.2 GRDB

- `Infrastructure/Database/DatabaseMigrator.swift` → `multiPhotoSourceSQL`：一条 `execute(sql:)` 内含多条 `ALTER TABLE ... ADD COLUMN` + `CREATE TABLE/INDEX` + `UPDATE`。确认 GRDB 逐条执行成功；**尤其在已有 v1–v4 的旧库上升级**（不是只测全新库）。
- 列读取：`SearchRepository.map` / `AnalysisRepository.pendingVisionTasks` / `PhotoSourceRepository.map` 用了 `row["source_id"] as String?`、`let x: Int64? = row["file_size"]`、`row["root_bookmark"]`(Data?) 等。确认 GRDB 的泛型下标推断成立。
- `PhotoAssetRepository.upsert`：`values` 数组里有一个裸 `nil`（file_bookmark）和 `Int64?`(file_size)。确认 `StatementArguments(values)` 接受。
- `PhotoSourceRepository.upsert`：`arguments: [...]` 数组字面量含 `Data?`/`String?`，确认 ExpressibleByArrayLiteral 推断成 `StatementArguments`。

### 2.3 AVFoundation / ImageIO

- `LocalMediaSupport.swift` → `AVAssetImageGenerator.copyCGImage(at:actualTime:)` 在 macOS 13+ 标记弃用。**预期只是 warning**；若在 macOS 26 变成 error，改用异步 `generator.image(at:)`（需把 `videoPosterFrame` 改 async，并相应调整 `makeThumbnail` / 评分取帧链路）。
- `imageThumbnail` 的 `kCGImageSourceThumbnailMaxPixelSize: max(64, maxPixel)`：确认 `CFDictionary` 值装箱无误。

### 2.4 仅 warning（可暂不处理）

- `Presentation/Photos/PhotoGridView.swift` 顶部 `import Photos` 现已不直接使用 → 未使用导入 warning。
- `LocalMediaSupport.swift` 的 `import UniformTypeIdentifiers` 实际未用 → 可删。

## 3. 多照片源功能验证（M1–M5）

### 3.1 回归：系统图库不能坏

先确认现有系统图库全链路正常（这是底线）：

- 首次启动授权、分阶段导入、网格滚动/预热/触底加载。
- 查看器：图片/视频/Live Photo、左右切换、收藏(`.`)、信息(`⌘I`)、删除(`⌘⌫`)、废片篓(`T`)。
- 评分：评分进行中 **不再逐批刷新**（整轮结束刷新一次），进度条仍实时。
- Find(`⌘K`) 筛选实时更新。
- 升级既有库（v4→v5）后，老照片仍在、评分仍在。

### 3.2 新功能：本地目录源

在「设置 → 照片源」：

1. **添加本地文件夹**：点「添加本地文件夹」→ NSOpenPanel 选目录 → 后台扫描导入 → 网格出现本地照片。
2. **缩略图**：本地图片缩略图正常、无拉伸畸变；本地**视频**显示首帧海报。
3. **查看器**：打开本地图片可缩放/平移/双击/滑动；打开本地**视频**能播放（AVURLAsset）。
4. **评分**：对本地图片评分出分；本地视频评分用抽帧（确认不崩）。
5. **收藏**：本地照片收藏只更新 App 内状态（不写系统）。
6. **删除**：本地照片删除 → 进入**系统废纸篓**（`FileManager.trashItem`），不是硬删除。
7. **重扫**：目录里新增/删除文件后点「重新扫描」能同步。
8. **移除源**：移除后该源照片从库消失（级联删除），系统源不可移除。
9. **混合**：系统 + 本地照片在同一网格共存、互不串味（缩略图/查看器/评分按源路由）。
10. **重启**：重启 app 后本地源仍可访问（安全作用域书签解析成功）。

### 3.3 数据库

- 全新库：跑完迁移有 5 条 `schema_migrations`，存在 `photo_sources` 表与 `photo_assets.source_id` 列，且有一行 `system_photos`（`swift test` 已覆盖）。
- 旧库升级：v4 库升级到 v5 不报错、存量行 `source_id='system_photos'`、`source_asset_key=local_identifier` 回填正确。

## 5. 已知保守取舍（**非缺陷**，按需再做）

- **FSEvents 实时监听未做**：本地源用「手动重扫」。后续可加 `FSEventStream` 自动增量同步。
- **跨源去重为基础版**：`content_hash` 列已就绪但导入未逐文件计算（大库性能）；唯一性靠 `(source_id, source_asset_key)`。
- **本地 Live Photo 不配对**：本地资产仅 image/video（`.heic+.mov` 配对、Google Motion 未做）。
- **本地视频精确尺寸/时长**导入阶段从略（需异步 `AVAsset.load`）；不影响网格与评分。
- **移除源未显式 `stopAccessingSecurityScopedResource`**：依赖 app 退出释放；如需严谨可在 registry 保存 URL 并在 unregister 时停。
- **本地截图识别**：本地资产无 `PHAssetMediaSubtype`，截图强制 0 分规则对本地不生效（可后续按文件名/EXIF 兜底）。
