# MantaPhotos Liquid Glass 重构清单

目标：在不牺牲照片网格性能的前提下，把主界面从“手工拼装的玻璃风格”提升为更接近 macOS 原生 Liquid Glass 的视觉与交互体验。

## 现状判断

- 主窗口入口已经是 SwiftUI，`AppShellView` 负责整体壳子。
- 照片网格仍然是 AppKit 的 `NSCollectionView`，这部分是性能核心，不建议为了视觉风格直接替换。
- 当前界面已经大量使用 `Material`，但也混入了不少自定义渐变、固定高度条、强对比黑色遮罩和手工圆角面板，整体更像“自定义皮肤”而不是“系统玻璃”。

## 优先级 1：主壳子收口到系统结构

### 建议重构

- 把 `AppShellView` 的顶部栏、内容区、底栏三段式手工布局，逐步迁移到更标准的 macOS 容器结构。
- 优先考虑 `NavigationSplitView`、系统 `toolbar`、`searchable` 和更轻的 sheet / overlay 组织方式。
- 去掉主窗口里过于显眼的自绘分割线和固定壳层，让系统自己承担“浮动玻璃”的观感。

### 目标效果

- 侧栏、搜索、主要操作更像 macOS 自带工具栏。
- 内容区更干净，层级更少。
- 窗口边缘与滚动边缘更自然。

## 优先级 2：侧栏改成更轻的筛选面板

### 现状

- `SidebarView` 用大量 chip、渐变按钮、FlowLayout 和自定义背景堆出密集筛选面板。
- 现在可用，但视觉密度偏高，且每个筛选项都像独立小卡片。

### 建议重构

- 保留高价值筛选项，减少“标签化”装饰。
- 把高频切换项做得更接近原生行式控件或轻量胶囊。
- 限制渐变使用范围，只保留少数强调态，不要让所有 active 状态都像品牌按钮。
- 让 sidebar 本体更接近系统 source list / inspector 的气质。

### 目标效果

- 更轻、更克制、更像系统侧栏。
- 视觉焦点更集中，筛选效率更高。

## 优先级 3：Find 浮层改成真正的玻璃搜索面板

### 现状

- `FindOverlayView` 现在是固定尺寸的大面板，外层有全屏黑色遮罩，内部还有较重的分区和底栏。

### 建议重构

- 降低黑色遮罩权重，避免把玻璃感压暗。
- 把搜索字段、清空、关闭、摘要这几个核心动作收紧到更小的玻璃表面。
- 减少底部黑色半透明条，改成更轻的系统材质。
- 让浮层更像 macOS 的搜索面板，而不是弹出的自定义设置页。

### 目标效果

- 更通透。
- 更轻。
- 更像系统级搜索/筛选弹窗。

## 优先级 4：查看器 chrome 变薄，媒体区保留

### 现状

- `PhotoViewerView` 的媒体展示逻辑是对的，但顶部控制条和右侧信息面板偏重。
- 大块黑底和强覆盖式 chrome 会削弱 Liquid Glass 的层次感。

### 建议重构

- 保留 `VideoPlayer`、`PHLivePhotoView` 和媒体加载逻辑。
- 将顶部操作条和右侧信息栏做得更像悬浮玻璃组件，而不是贴在内容上的面板。
- 减少整屏黑色底层的存在感，更多依赖内容自身的对比和局部材料。

### 目标效果

- 媒体内容更突出。
- 控制条更轻。
- 信息面板更像“浮在内容之上”的系统组件。

## 优先级 5：照片页工具条系统化

### 现状

- `PhotosToolbarView` 已经功能完整，但布局是定制 HStack。
- 工具按钮、筛选状态、排序、缩放和 badge 切换都放在一条自定义条带里。

### 建议重构

- 把导入、评分、排序、缩放、badge 选择拆分成更标准的 toolbar 分组。
- 让搜索和筛选更符合 macOS 的工具栏语义。
- 尽量减少固定高度和固定宽度的人工排布。

### 目标效果

- 更原生。
- 更适合宽窗口。
- 更容易适配未来的系统玻璃样式变化。

## 保持不动的部分

- `PhotoGridView` 的 `NSCollectionView` 网格实现先不要替换。
- 缩略图预热、差分数据源、滚动触底加载、选择行为这些性能和交互核心也不要为了外观轻易重写。
- `LivePhoto` 播放桥接和图片/视频媒体请求逻辑先保留。

## 建议的改造顺序

1. 先重构 `AppShellView` 的结构和窗口壳子。
2. 再压缩 `SidebarView` 的视觉重量。
3. 之后改 `FindOverlayView`，把它变成更轻的玻璃面板。
4. 再处理 `PhotoViewerView` 的 chrome。
5. 最后把 `PhotosToolbarView` 收进更标准的工具栏模型。

## 一句话结论

MantaPhotos 已经有 SwiftUI 壳子了，下一步不是“继续加更多效果”，而是“减少手工 chrome，增加系统结构”，这样才能更接近 Liquid Glass，同时保持照片网格的性能底盘。
