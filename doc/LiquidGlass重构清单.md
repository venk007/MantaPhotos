# MantaPhotos Liquid Glass 重构清单

目标：在不牺牲照片网格性能的前提下，把主界面从“手工拼装的玻璃风格”提升为更接近 macOS 原生 Liquid Glass 的视觉与交互体验。

> 执行状态（2026-06-08，第一轮）：P2 / P3 / P4 / P5 的「减手工 chrome」轮已落地，核心是把散落在各视图里的品牌渐变、黑色遮罩与魔法圆角收敛进 `DesignSystem`。
>
> 执行状态（2026-06-08，第二轮 / P1）：P1 改以**底部液态玻璃导航坞**落地（而非 `NavigationSplitView` 整改）——按产品决策保留顶部标签，新增 iOS / visionOS 风格的底部悬浮玻璃导航 + 独立 🔍 搜索按钮；同时把查看器快捷键对齐 Apple 照片、补齐缩放/平移/滑动手势。详见末尾「执行记录（第二轮）」。

## 现状判断

- 主窗口入口已经是 SwiftUI，`AppShellView` 负责整体壳子。
- 照片网格仍然是 AppKit 的 `NSCollectionView`，这部分是性能核心，不建议为了视觉风格直接替换。
- 当前界面已经大量使用 `Material`，但也混入了不少自定义渐变、固定高度条、强对比黑色遮罩和手工圆角面板，整体更像“自定义皮肤”而不是“系统玻璃”。

## 优先级 1：主壳子收口到系统结构 ✅ 已做（改为底部导航坞方案）

### 建议重构

- 把 `AppShellView` 的顶部栏、内容区、底栏三段式手工布局，逐步迁移到更标准的 macOS 容器结构。
- 优先考虑 `NavigationSplitView`、系统 `toolbar`、`searchable` 和更轻的 sheet / overlay 组织方式。
- 去掉主窗口里过于显眼的自绘分割线和固定壳层，让系统自己承担“浮动玻璃”的观感。

### 目标效果

- 侧栏、搜索、主要操作更像 macOS 自带工具栏。
- 内容区更干净，层级更少。
- 窗口边缘与滚动边缘更自然。

## 优先级 2：侧栏改成更轻的筛选面板 ✅ 本轮已做

### 现状

- `SidebarView` 用大量 chip、渐变按钮、FlowLayout 和自定义背景堆出密集筛选面板。
- 现在可用，但视觉密度偏高，且每个筛选项都像独立小卡片。

### 建议重构

- 保留高价值筛选项，减少“标签化”装饰。
- 把高频切换项做得更接近原生行式控件或轻量胶囊。
- 限制渐变使用范围，只保留少数强调态，不要让所有 active 状态都像品牌按钮。
- 让 sidebar 本体更接近系统 source list / inspector 的气质。

### 目标效果

- 更轻、更克制、更像系统侧栏。
- 视觉焦点更集中，筛选效率更高。

## 优先级 3：Find 浮层改成真正的玻璃搜索面板 ✅ 本轮已做

### 现状

- `FindOverlayView` 现在是固定尺寸的大面板，外层有全屏黑色遮罩，内部还有较重的分区和底栏。

### 建议重构

- 降低黑色遮罩权重，避免把玻璃感压暗。
- 把搜索字段、清空、关闭、摘要这几个核心动作收紧到更小的玻璃表面。
- 减少底部黑色半透明条，改成更轻的系统材质。
- 让浮层更像 macOS 的搜索面板，而不是弹出的自定义设置页。

### 目标效果

- 更通透。
- 更轻。
- 更像系统级搜索/筛选弹窗。

## 优先级 4：查看器 chrome 变薄，媒体区保留 ✅ 本轮已做

### 现状

- `PhotoViewerView` 的媒体展示逻辑是对的，但顶部控制条和右侧信息面板偏重。
- 大块黑底和强覆盖式 chrome 会削弱 Liquid Glass 的层次感。

### 建议重构

- 保留 `VideoPlayer`、`PHLivePhotoView` 和媒体加载逻辑。
- 将顶部操作条和右侧信息栏做得更像悬浮玻璃组件，而不是贴在内容上的面板。
- 减少整屏黑色底层的存在感，更多依赖内容自身的对比和局部材料。

### 目标效果

- 媒体内容更突出。
- 控制条更轻。
- 信息面板更像“浮在内容之上”的系统组件。

## 优先级 5：照片页工具条系统化 ◐ 部分（强调色已收敛，toolbar 语义化待续）

### 现状

- `PhotosToolbarView` 已经功能完整，但布局是定制 HStack。
- 工具按钮、筛选状态、排序、缩放和 badge 切换都放在一条自定义条带里。

### 建议重构

- 把导入、评分、排序、缩放、badge 选择拆分成更标准的 toolbar 分组。
- 让搜索和筛选更符合 macOS 的工具栏语义。
- 尽量减少固定高度和固定宽度的人工排布。

### 目标效果

- 更原生。
- 更适合宽窗口。
- 更容易适配未来的系统玻璃样式变化。

## 保持不动的部分

- `PhotoGridView` 的 `NSCollectionView` 网格实现先不要替换。
- 缩略图预热、差分数据源、滚动触底加载、选择行为这些性能和交互核心也不要为了外观轻易重写。
- `LivePhoto` 播放桥接和图片/视频媒体请求逻辑先保留。

## 建议的改造顺序

1. 先重构 `AppShellView` 的结构和窗口壳子。
2. 再压缩 `SidebarView` 的视觉重量。
3. 之后改 `FindOverlayView`，把它变成更轻的玻璃面板。
4. 再处理 `PhotoViewerView` 的 chrome。
5. 最后把 `PhotosToolbarView` 收进更标准的工具栏模型。

## 一句话结论

MantaPhotos 已经有 SwiftUI 壳子了，下一步不是“继续加更多效果”，而是“减少手工 chrome，增加系统结构”，这样才能更接近 Liquid Glass，同时保持照片网格的性能底盘。

## 执行记录（2026-06-08）

本轮以「令牌集中 + 减手工 chrome」为主线，统一了之前散落在各视图里的玻璃常量，未触碰照片网格性能底盘。

设计令牌（`DesignSystem.swift`）：

- 新增 `Glass` 命名空间：`hairline` / `hairlineWidth`（统一玻璃发丝描边）、`activeTint`（选中态统一为系统强调色 `Color.accentColor`）、`scrimLight` / `scrimDark`（更轻的浮层遮罩）、`viewerBackdrop`（查看器底色 0.9，不再死黑）、`brandGradient`（唯一保留的品牌渐变，仅用于少数信号性强调态）。
- `Radius` 新增 `chip` / `card` / `overlay`，替换页面里手写的 12 / 16 / 18 魔法圆角。

各视图改动：

- 侧栏（P2）：filter chip、score 运算符按钮的 active 态从紫色品牌渐变改为系统强调色；删除局部 `activeGradient` 重复定义。
- Find 浮层（P3）：黑色全屏遮罩权重下调（0.16/0.28 → 0.12/0.22）；顶部计数条与底部摘要条的黑色半透明背景改为系统 `.quaternary` 材质；浮层圆角/描边改用 `overlay` + `hairline` 令牌；阴影减轻；所有 active chip 收敛为强调色。
- 查看器（P4）：整屏底色改用 `viewerBackdrop`；顶部关闭/翻页按钮收进两枚悬浮玻璃胶囊（`.ultraThinMaterial` + 发丝描边）；底部操作条从贴边整条改为内缩的悬浮圆角玻璃条；媒体加载、`VideoPlayer`、`PHLivePhotoView` 逻辑完全未动。
- 照片页工具条（P5 部分）：角标指标段控的选中态改用集中后的 `brandGradient` 令牌；删除内联渐变。
- 主壳子：搜索入口胶囊与侧栏浮层的描边统一为 `hairline` 令牌，圆角改用 `overlay`。

P1 为什么延后（第一轮的判断）：把 `AppShellView` 三段式手工布局迁移到 `NavigationSplitView` 是结构性重写，第一轮在无工具链下盲改风险过高，故先延后。

编译验证说明：本轮在 Linux 沙箱完成，无 Swift/Xcode 工具链，且代码依赖 AppKit/SwiftUI/Photos/Vision 等 macOS 专有框架，**无法执行真实编译**。已做的校验为：括号/引号配平静态检查、令牌引用全量核对（无残留内联渐变、无悬空 `activeGradient`）。请在 Mac 上以 `xcodebuild` / Xcode 跑一次构建确认。

## 执行记录（2026-06-08 第二轮 / P1 + 快捷键 + 手势）

产品决策：不走 `NavigationSplitView`，**保留顶部标签**，改为新增底部 iOS 风格液态玻璃导航坞。

壳子结构（`AppShellView`）：

- 新增 `LiquidGlassDock`：底部居中的悬浮玻璃胶囊，承载四个分区（Photos / Timeline / Reports / Settings）的快速跳转，active 分区展开标题并用系统强调色填充；右侧是一枚**独立的圆形玻璃 🔍 按钮**，打开 Find 浮层。整体 `regularMaterial` + 发丝描边 + 轻投影，悬浮于内容之上。
- 顶部栏移除中部搜索胶囊（搜索入口统一收到底部 🔍，避免双搜索冗余），保留 logo、分区标签与右侧主题 / 分析进度。
- 照片网格底部 `sectionInset` 由 24 增大到 96，为悬浮导航坞 + 状态条预留空间，最后一行不被遮挡。
- Find 浮层展开时导航坞淡出下移，避免与浮层叠加。

查看器快捷键（对齐 Apple 照片，`PhotoViewerView` / 菜单栏）：

- 上一张 / 下一张：`←` / `→`
- 播放 / 暂停（视频 & Live）：`空格`
- 收藏：`.`（句点，Apple 标准）
- 查看信息：`⌘I`
- 删除到系统照片：`⌘⌫`
- 放入 / 移出废片篓（App 软删除，自定义）：`T`
- 关闭：`Esc`
- 网格缩放：`⌘+` / `⌘-`（菜单栏 View 命令，全局可用）
- `⌘K`：Find 浮层（既有）

查看器手势（`PhotoViewerView`，作用于静态图）：

- 捏合缩放：`MagnificationGesture`，范围 1×–6×。
- 拖拽平移：放大后拖动平移图片。
- 双击：在「适配」与 2.5× 之间切换。
- 左右滑动：未放大时左/右拖拽切换上一/下一张（阈值 60pt）。
- 切换照片自动复位缩放；视频 / 播放中的 Live Photo 仍用方向键与按钮切换。
- 网格：捏合改变缩放级别（既有 `NSMagnificationGestureRecognizer`，未改动）。

性能与底盘：`PhotoGridView` 的 `NSCollectionView`、差分数据源、缩略图预热、触底加载与滚动联动侧栏逻辑均未改动，仅调整了底部留白。
