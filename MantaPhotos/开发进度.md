## 1. 使用规则

- 每次开始开发前，先阅读本文档，再查看相关实现方案和代码。
- 每次完成开发或遇到阻塞后，必须更新本文档。
- 每条任务状态只使用：`未开始` / `开发中` / `已完成` / `阻塞` / `延期`。
- 如果修改了阶段范围、技术决策、数据库 schema、快捷键、权限或数据语义，必须同步记录到“决策记录”。
- “下次接手提示”必须保持可执行，方便下一次直接继续。

## 7. 当前开发中

当前开发中：

- P0 照片墙：`NSCollectionView` 已可显示真实 Photos 缩略图，7 级缩放和角标可用；已修复侧栏跨页面显示和返回照片页分层错乱；已接 diffable data source、可见区前后缓冲预热、滚动隐藏侧栏和触底分页懒加载，真实图库已验证从 3,000 增量加载到 12,000。
- P0 首次导入：`PhotoLibraryImportUseCase` 已实现首批 3,000 + 后台完整导入；真实 54,247 图库验证首屏可见、后台进度可见。
- P0 查找/筛选：侧边栏和查找浮层已接同一份 `SearchFilterState`，可实时驱动照片墙；截图和设备来源已落 SQL；排序已支持最新、最早、评分高到低、评分低到高；`Cmd+K` 打开、`Esc` 关闭、关闭后恢复侧栏状态已验证；地点/人物/标签先保留 demo 对齐骨架，等待数据源接入。
- P0 查看器：已接收藏、应用内废片篓、真正删除确认入口和 `Esc/i/←/→/T/F/⌘D/Space` 快捷键；视频使用 `AVKit.VideoPlayer`，Live Photo 使用 `PHLivePhotoView`，静态照片 `Space` 保持 no-op。
- P1 打分：Score 菜单可对已加载照片或全部匹配结果发起 Apple Vision 美学评分，分数写入 `analysis_outputs` 和 `photo_scores` 并显示在照片墙/查看器；暂停/继续/停止、失败任务重置重试和失败后顶栏重试入口已完成首版。
- P0 语言与 demo 对齐：顶部菜单栏已按 demo 顺序和布局修正；主界面、侧栏、照片页工具栏、排序控件、设置页、底栏导入进度支持中文，切换中文后已可视验证生效。

下一步建议：

1. 做 `NSCollectionView` 全量触底长滚动专项压测，继续观察 diffable/preheat/lazy loading 后的灰色占位、滚动掉帧和连续分页稳定性。
2. 为正式 `.app` / `.xcodeproj` 补 `NSPhotoLibraryUsageDescription`、bundle identifier、签名配置；当前 SwiftPM 裸可执行需要临时 debug app bundle 才能完整验证权限和窗口。
3. 做 P1 真实全图库长跑专项：重点观察 54,247 资产评分耗时、失败项数量、暂停/恢复后的 DB 状态和 UI 进度。
4. 为人物/标签/地点筛选接真实数据表与空数据态；在 P4+ 前不启用自定义模型结果。
